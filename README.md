# Stock-olm

Stock-olm 서비스 통합 레포지토리입니다.

[서비스 바로 가기](https://stock-olm.sublumen.xyz)

## 주요 기능

- 종목, 환율, 뉴스, 레포트 상세 검색
- 실시간 차트 데이터 조회
- 전략 비교, 백테스트
- 시황, 종목 분석
